**Fusion Fixer by RydenVR**

Fusion Fixer is a BONELAB mod project by RydenVR, designed to investigate and help prevent crashes related to NPC deaths when using regular Fusion. The goal is to improve game stability and make gameplay smoother.

**Status:** In development. The current version is a starter build and does not yet contain the actual NPC crash fix.

**Creator:** RydenVR  
**Game:** BONELAB  
**Platform:** Meta Quest 2 compatibility is a goal  
**Project:** Fusion Fixer
